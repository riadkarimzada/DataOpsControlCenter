# DataOps Control Center

DataOps Control Center is a full-stack dashboard for monitoring data pipelines, data quality checks, incidents, and deployment status.

I am building this project to practice software engineering, data engineering, and developer tooling concepts in one project.

## Planned Tech Stack

### Frontend
- React
- TypeScript
- Vite
- React Router
- TanStack Query

### Backend
- Python
- FastAPI
- SQLAlchemy
- Alembic

### Database
- PostgreSQL

### DevOps
- Docker
- Docker Compose
- GitHub Actions
- Git and GitHub pull-request workflow

## Planned Features

- Pipeline registry
- Pipeline run history
- Data quality checks
- Incident tracking
- Deployment status page
- PostgreSQL-backed backend API
- React dashboard UI
- CI workflow with GitHub Actions

## Project Status

This project is currently in early development.

## Why this project?

The goal is to build a realistic internal engineering dashboard that combines:

- data pipeline monitoring
- REST API development
- relational database modeling
- frontend dashboard development
- CI/CD basics
- GitHub workflow practice

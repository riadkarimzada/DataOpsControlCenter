# Current Limitations

This project is still in early development.

Planned limitations for the first version:

- Pipeline execution will be simulated.
- Deployment data will be seeded manually.
- Authentication will not be implemented in the first version.
- The dashboard will not connect to a real Azure DevOps organization yet.
- Data quality checks will first be stored as metadata, not computed from real datasets.

These limitations are intentional because the first goal is to build a clean full-stack structure before adding more advanced integrations.
